# VPS Guard

VPS Guard 是独立的中文服务器加固工具，提供防火墙端口管理、SSH 端口切换及 Fail2ban 管理菜单。支持 Debian、Ubuntu、Rocky、AlmaLinux 和 RHEL 家族，具体版本及限制见[操作手册](MANUAL.md)。

## 一键安装并启动

在服务器的 SSH 交互终端执行（需要 curl、Bash、GNU 工具及 root 或 sudo）：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/wx11xz111/vps-guard/main/bootstrap.sh)
```

安装器校验固定版本的文件，再安装至 `/usr/local/lib/vpsmanager/server-guard`，并打开中文菜单。后续使用：

```bash
vps-guard
```

可在任意目录调用；普通用户会提示 sudo 验证，并保留当前 SSH 会话信息。菜单按“防火墙与端口 → SSH 与防爆破 → 状态与维护”分组。已安装旧版时，重新执行一键安装命令即可更新。

操作前的提示统一为 `[y/N]`：`Y/y` 执行，`N/n` 或回车取消。执行成功后立即生效，不再要求新开 SSH 确认，不创建待确认记录或自动回退任务；可在同一连接连续操作。

终端使用不同颜色区分内容：青蓝色为标题/查看信息，绿色为启用/成功，黄色为提醒/确认，红色为错误/删除/清空，紫色为输入提示。重定向或管道输出自动使用纯文本；可用 `NO_COLOR=1 vps-guard` 关闭颜色。

菜单 `16 查看完整规则` 显示当前管理器的实际规则，包含工具之外配置的规则；`17 配置防爆破` 设置 SSH 认证失败次数、统计窗口和封禁时长；`18 查看备份` 列出备份编号、动作、执行状态及校验结果。原菜单 13/14/15 的恢复、确认和回退入口已取消。

防火墙日常操作使用 `19 启动`、`10 关闭（保留规则）`、`20 重启/重载`，首次安装仍选 `1`。关闭不再清空端口配置，重新启动会先补齐 SSH 放行，再加载已保存规则；清空规则仍是独立的 11/12 号操作。UFW/firewalld 重启采用重载，firewalld 会重新读取永久配置。

菜单 `21 Fail2ban防护管理` 集中提供安装启用、停用本工具 SSH 防护、参数、状态及封禁列表、单 IP 解封、持久白名单、日志和服务重启。服务重启涉及全部 jail；停用、解封及白名单操作仅管理本工具 jail。首次启用默认 5 次失败、600 秒窗口、3600 秒封禁，后续保留已有参数和白名单。

SSH 改端口会检查 TCP 占用，先放行防火墙，校验及重载 SSH，确认新端口确实由 sshd 监听，再同步本工具 Fail2ban jail 的全部 SSH 端口。保留原 SSH 端口；已停止的 Fail2ban 服务或已停用的 jail 保持原状态。其他工具的 jail 不会被改写。检测到 socket 激活时，在确认预览中说明切换到 SSH 服务监听，仅在服务具备保留会话的设置时执行，不自动解除管理员的 mask。

安装过程不修改防火墙或 SSH 配置。菜单中的变更需要预览及确认；启用 Fail2ban 不要求先启动防火墙。详细操作、依赖和备份说明见[操作手册](MANUAL.md)。

菜单 `7 安装并启用 Fail2ban` 在缺少软件时，会先预览安装计划，输入 Y/y 后使用系统软件源安装服务端与 systemd 日志依赖，再启用 SSH jail、设置开机启动并验证就绪。菜单 17 的自定义防爆破参数也支持此流程。取消或仅预览不会安装软件；失败会报告当前结果并保留备份，已安装的软件包保留。

升级后首次进入菜单或执行变更时，会停用旧版确认/回退任务并归档旧 `pending` 记录，保留当前配置，不再因上一笔未确认而阻止操作。失败时不自动恢复，配置备份仍保留供检查。

如服务器尚未安装或启用防火墙，选择 **1 安装并启用防火墙**：Debian/Ubuntu 使用 UFW，RHEL/Rocky/Alma 使用 firewalld。脚本先识别和放行当前会话、配置及监听中的全部 SSH 端口，再启用并核对防火墙；已有其他管理器或不支持的规则会提前拒绝。业务端口需随后按需放行。

## 验证状态

先前已在 Ubuntu 24.04 公网服务器验证 SSH 登录、只读查询及菜单；立即生效流程和本次操作流程使用隔离命令适配器验证，完整 Linux 回归仍需复跑。真实防火墙/SSH 变更、系统重启和 SELinux 内核仍需实机验收。使用前请保留云厂商救援入口，并确保云安全组允许当前 SSH 端口。
